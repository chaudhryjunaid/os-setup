# os-setup

Scripts that rebuild my dev machines after a reinstall, one directory per OS.

| Directory | Target |
| --- | --- |
| [`ubuntu-setup/`](ubuntu-setup/) | Ubuntu 26.04 dev machine: staged, re-runnable bash steps |
| [`fedora-setup/`](fedora-setup/) | Fedora 44 Workstation: one-shot `setup.sh` |

```sh
git clone https://github.com/chaudhryjunaid/os-setup ~/setup/os-setup
```

Then follow the README in the directory for your OS. Dotfiles come from [rcfiles](https://github.com/chaudhryjunaid/rcfiles).
